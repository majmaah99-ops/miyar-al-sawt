# مِعيار الصوت | MIYAR AI

مشروع أولي لتدقيق عتبات كشف التزييف الصوتي، مع قياس فجوة نقل العتبة من بيانات المعايرة إلى بيانات الاختبار.

## ما يعمل الآن
- واجهة Streamlit عربية لتحليل ملف درجات وقياس Precision وRecall وFPR وHTER وEER الوصفي.
- اختيار العتبة من **calibration** حصريًا وتقييمها على **test** دون إعادة ضبط.
- ثلاثة أوضاع: `conservative` و`balanced` و`sensitive`.
- تجارب مثال مُعلّمة بوضوح بأنها اصطناعية وليست نتائج كشف حقيقية.
- اختبارات وحدات لكود تحليل العتبات.

## التشغيل

```bash
python -m pip install -r requirements.txt
python -m streamlit run dashboard.py
python -m pytest -q
```

## حدود النسخة
لا تتضمن هذه النسخة أوزان نموذج كشف الصوت، ولذلك فإن رفع صوت حقيقي **لا ينتج كشفًا فعليًا** حتى توصيل النموذج المُدرَّب رسميًا. لا تُعرض درجات الملفات التجريبية على أنها نتائج حقيقية.

> مشروع تجريبي للمشاركة في تحدي DeepFake — لا يُستخدم لاتخاذ قرارات قضائية أو اتهام أشخاص.

## حماية الخصوصية
لا ترفع تسجيلات شخصية، أو بيانات حساسة، أو مفاتيح وصول، أو أوزان كبيرة إلى المستودع. استخدم مجموعات بيانات مرخصة.



## تجربة كشف صوت حقيقي على Streamlit (نوفمبر 2026)

رابط التطبيق: https://miyar-al-sawt.streamlit.app/

1. افتح تبويب «فحص ملف صوتي».
2. اختر «نموذج سحابي خفيف — تجربة فورية» (الاختيار الافتراضي).
3. ارفع **WAV أو FLAC** يحتوي على كلام مسموح لك باستخدامه (أقل من 25MB و120 ثانية).
4. **لا تحتاج ملف JSON** في التجربة الأولى؛ اتركه فارغًا.
5. اضغط «تحليل الصوت فعليًا». عند أول تشغيل يحاول الخادم تنزيل نموذج ONNX مضغوط من Hugging Face، ثم يستدل على التسجيل باستخدام CPU.

النموذج: [nakas/gpttrace-wavlm-audio-v3](https://huggingface.co/nakas/gpttrace-wavlm-audio-v3) (رخصة CC BY-SA 4.0، ~122MB). لم يتم تدريبه أو معايرته خصوصًا للعربية؛ يجب اختبار أدائه على العربية قبل اعتبار النتائج قابلة للاعتماد. **درجة الاشتباه raw logit وليست احتمال تزييف.** من دون JSON متوافق، تُستخدم عتبة صفر أولية وغير معايرة، ويجب التعامل مع الناتج كمؤشر تجريبي فقط.

خيار «النموذج العربي الكبير» يحتاج إعداد DeepFense وأوزانه بشكل منفصل ولا يزال غير مفعل على Streamlit Cloud.

> إذا فشل تنزيل النموذج، أو تجاوز حدود ذاكرة Cloud، افتح Manage app → Logs. قد يلزم استخدام استضافة ذات موارد أكبر. لا تدّع دقة كشف أو نجاح تشغيل النموذج الفعلي قبل التحقق على الموقع.

### معايرة العتبة الصحيحة

لا تستخدم ملف `examples/DEMO_SYNTHETIC_scores.csv` لاتخاذ قرار عن تسجيلات حقيقية. أنشئ ملف manifest محليًا يحوي `audio_id,path,split,label,group_id,domain` مع مجموعتي معايرة واختبار منفصلتين بحسب المتحدث/المصدر؛ ثم:

```bash
python score_light_manifest.py --manifest my_manifest.csv --output scores_light_real.csv
python audit.py --csv scores_light_real.csv --policy conservative --max-fpr 0.05 --output light_threshold_report.json
```

بعدها يمكنك رفع `light_threshold_report.json` في خانة JSON الاختيارية. يتحقق التطبيق من تطابق `model_id` و`aggregation` مع النموذج النشط قبل تطبيق العتبة.

### الشفافية العلمية

- يطبق النموذج 4 نوافذ صوتية (كل واحدة 4 ثوانٍ) مع متوسط `AI minus human`، **ولا يوفر تحديدًا موثوقًا لمكان كلمة تم تزييفها**.
- درجات النوافذ مؤشرات استكشافية؛ ليست خرائط أدلة جنائية.
- أوزان النموذج تنزل من Hugging Face ولا تُرفع إلى المستودع.
- تشغيل اختبارات GitHub يتحقق من صحة المعالجة والأكواد باستخدام نماذج وهمية، وليس أداء الكاشف العصبي على تسجيلات حقيقية.
